# 公开边界

## 仓库定位

这是一个公开可读的设计案例，不是开源软件，也不是源码镜像。

## 可以公开

- 设计目标与取舍
- 页面职责和信息层级
- 抽象的环境分层图
- 桌面与手机的布局差异
- 不含精确参数的质量检查方法
- 已知的视觉陷阱与避免方式

## 不公开

### 前端实现

- HTML 结构
- CSS 选择器、变量与精确设计令牌
- JavaScript 交互逻辑
- WebGL Shader、雨滴模型与纹理处理
- Service Worker 与缓存策略代码
- 可直接运行或重建界面的工程文件

### 后端实现

- 服务端源码
- API 路由与请求格式
- 数据库表与迁移
- 鉴权、配对和访问控制
- 模型 Provider、上下文、记忆与可靠发送链路
- 日志、诊断和部署配置

### 资产与数据

- 原始背景图
- 水滴纹理、图标源文件和字体文件
- 真实聊天、人物信息、关系资料和私人配置
- 密钥、令牌、地址、设备信息与本机路径

## 发布前检查

公开仓库中只允许 Markdown 文档和 GitHub 可渲染的抽象图。任何可执行文件、网页文件、素材文件、压缩包或构建配置都应被视为越界。

## 引用方式

可以链接到仓库并讨论其中的设计思想。复制界面、重建相同视觉、转载图文或将其用于商业项目，需要另行取得授权。
