# 视觉系统

## 1. 场景优先

界面不是先画卡片、再随便补一张背景。场景先确定光线、方向、远近层次和主要色温，玻璃随后从同一环境中取得反射与折射依据。

这会带来两个直接结果：

- 卡片之间看起来属于同一个空间，而不是互不相关的半透明贴纸。
- 天气切换时，背景与控件会一起变化，不会出现“外面在下雨，卡片仍是晴天白玻璃”的割裂。

## 2. 清透玻璃，而不是磨砂白板

水晶玻璃的中央保持清楚。厚度主要通过边缘折射、柔和双层边、内高光、轻阴影和环境反射表达。

不使用以下做法：

- 给每张卡片铺高不透明度的白层
- 用强模糊掩盖背景细节
- 用硬白描边模拟厚度
- 给所有小按钮都套独立“玻璃泡泡”

可读性优先从文字和排版解决：真实字重、稳定对比、适度行距、必要时提供独立的易读模式。

## 3. 四级界面层级

| 层级 | 用途 | 视觉责任 |
| --- | --- | --- |
| 环境层 | 街景、天气、光照 | 提供空间与色温 |
| 主玻璃 | 首页主气泡、生活区 Today 卡 | 建立视觉焦点 |
| 次级玻璃 | 章节、共读、最近房间 | 承载可操作信息 |
| 轻信息面 | 标签、索引、辅助说明 | 保持低噪声，不与主玻璃竞争 |

玻璃层级越低，越不应该依赖模糊、阴影和高亮边。

## 4. 色彩策略

晴光状态以清透青绿和自然暖光为主；持续雨转向低饱和蓝紫；风暴加深环境对比，但不把文字整体染蓝。

颜色变化应遵循：

- 先改变环境，再改变玻璃材质
- 内容文字保持稳定的可读色
- 状态色只用于真正的状态，不充当装饰
- 雨天仍保留局部暖色，避免整屏变成灰蓝滤镜

## 5. 排版

界面正文使用适合长时间阅读的现代无衬线字体；首页标题、章节名和少量大标题可使用更舒展的衬线层级。

三种显示模式可以覆盖大部分需要：

- 现代：默认信息密度
- 阅读：更舒展的行距和字距
- 系统：跟随设备字体，减少额外依赖

公开参考不提供具体字号和字重数值。真正实现时，应以手机窄屏、中文长句和低对比背景作为测试基准。

## 6. 动效

动效只解释空间变化：

- 进入页面时，新玻璃从后方浮出
- 返回时，当前玻璃缩回原来的空间层级
- 天气沿相邻状态过渡，不突然跳色
- 减少动态效果开启时，立即停止持续动画

动效不承担“让界面显得高级”的任务；没有信息意义的持续漂浮、发光和缩放应当删除。
