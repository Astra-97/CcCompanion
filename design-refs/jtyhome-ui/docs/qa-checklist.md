# 设计复查清单

## 视觉

- [ ] 街景保持清楚，没有为了“玻璃感”叠加整屏白雾
- [ ] 主玻璃、次级玻璃和轻信息面的层级能够一眼区分
- [ ] 玻璃中央透明，厚度主要出现在边缘
- [ ] 中文长句在最复杂背景上仍然可读
- [ ] 按钮、状态色和装饰色没有互相抢夺注意力

## 雨景

- [ ] 桌面与手机使用各自正确构图
- [ ] 持续雨的雨滴透明、稀疏、偏大、带轻高光
- [ ] 没有密集颗粒、强黑边、蓝灰雾或满屏雨丝
- [ ] WebGL 加载前和失败时仍使用当前正式场景
- [ ] 缓存清单没有残留废弃雨景素材

## 响应式

- [ ] 手机首屏只保留当前任务和高频入口
- [ ] 底部导航避开 Home Indicator
- [ ] 软键盘不会同时挤坏消息区、输入区和导航
- [ ] 横屏、小屏和动态工具栏下没有不可触达内容
- [ ] 桌面卡片没有被直接等比缩小后塞进手机

## 交互与可访问性

- [ ] 文字、按钮和结构都保留在 DOM 中
- [ ] 键盘可以到达主要交互
- [ ] 控件有可理解的名称和状态
- [ ] 减少动态效果开启后，持续动画确实停止
- [ ] WebGL 或音频失败不会阻断主要界面

## 性能

- [ ] 页面隐藏时停止持续绘制
- [ ] 晴天不运行雨水模拟
- [ ] 没有变化的水图不会重复上传
- [ ] 高分辨率屏幕受内部像素预算约束
- [ ] 每张卡片没有独立创建持续动画画布

## 公开发布

- [ ] 没有 HTML、CSS、JavaScript、Shader 或可运行 Demo
- [ ] 没有原图、纹理、字体、图标源文件或压缩包
- [ ] 没有 API 名称、服务地址、数据库结构或部署信息
- [ ] 没有真实聊天、姓名、私人规则或本机配置
- [ ] 文档明确标注“仅供设计参考，不是开源发行版”
